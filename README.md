# SplitMate AI 💰

An AI-powered expense-sharing application that makes splitting expenses and tracking spending easier.

## ✨ Features

- **Expense Splitting:** Calculate how much each member should pay.
- **AI Expense Insights:** Get insights into shared expenses.
- **Expense History:** Save and view previous transactions.
- **Search & Filter:** Find expenses by name and category.
- **Delete Expenses:** Remove unwanted transactions.
- **Analytics Dashboard:** View total spending, average expenses, highest expenses, and transaction counts.
- **Category Analytics:** Understand spending across different categories.
- **Monthly Analytics:** Track spending over time.

## 🚀 Getting Started

1. Clone this repository.
2. Install the required Python dependencies.
3. Run the FastAPI application:

```bash
uvicorn main:app --reload
```

4. Open `http://127.0.0.1:8000` in your browser.
